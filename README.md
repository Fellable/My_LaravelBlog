# MyLaravelBlog

Учебный блог на Laravel с административной панелью, API и Vue-компонентами.

## Запуск проекта

1. Клонируйте репозиторий.
2. Скопируйте `.env.example` в `.env`. Если вы меняли параметры в `docker-compose.yml`, внесите соответствующие изменения в `.env`.
3. Запустите Docker Compose.
4. Установите PHP-зависимости внутри PHP-контейнера:

   ```bash
   composer install
   ```

5. Заполните базу данных тестовыми публикациями:

   ```bash
   php artisan db:seed
   ```

6. Запустите Vite в отдельном терминале:

   ```bash
   npm run dev
   ```

## Возможности

- CRUD-интерфейс администратора для категорий, тегов, публикаций и пользователей.
- Слайдер изображений публикации на Vue 3.
- SortableJS для изменения порядка элементов в административной панели через API.
- Switchery для стилизации переключателей.
- Фабрики и сидеры для генерации тестовых публикаций.
- Пагинация публикаций и поиск по slug.
- Загрузка до 20 МБ изображений с динамическим добавлением полей слайдов.
- Отправка писем через очередь и Mailtrap.
- JWT-аутентификация API и Swagger-документация.
- Laravel Telescope, Laravel Debugbar и Sentry для диагностики.

## Полезные адреса

Замените `<host>` на имя хоста из вашей конфигурации:

- Telescope: `https://<host>:4477/telescope`
- Swagger UI: `https://<host>:4477/api/documentation`
- получение JWT-токена: `https://<host>:4477/api/auth/login`

## Очереди

Создание пользователя через административную панель использует очередь. Запустите обработчик:

```bash
php artisan queue:work
```

## Тесты

В проекте есть тесты регистрации, назначения роли администратора, доступа к административной панели и создания публикаций.

```bash
php artisan test --testdox
```

## Форматирование PHP

Проект использует Laravel Pint:

```bash
php vendor/bin/pint
```
